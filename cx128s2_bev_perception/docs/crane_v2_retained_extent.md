# Crane V2 · 긴 Cargo 표시 형상 유지

대상 조사 Bag: rosbag2_2026_11_03-06_07_41. 사용자가 녹색으로 관측된 약 12m 수평 구조물 전체를 Cargo라고 확인했다. 녹화된 공개 길이는 4.139m로 일정했지만, 현재 조각 중심과 폭·방향을 박스에 계속 적용해 중심 X가 약 2.83m 범위로 움직였다.

`RetainedExtent`는 표시에만 사용하는 별도 형상이다. 같은 확정 Cargo에서 Hook 연결이 직접 확인된 큰 실측의 폭·높이·방향과 Hook 기준 상대 중심을 기록한다. 이후 짧은 조각이 잡혀도 작은 조각의 중심/방향으로 박스를 다시 그리지 않는다. 더 큰 형상이 기존 표본보다 voxel_xy(기본 8cm) 이상 길어지면 형상 표본을 갱신한다. 공개 길이 자체는 기존 최대 길이 정책을 따른다.

박스 XY는 기록 시점의 상대 위치와 현재 실측 Hook XY로 이동한다. 연결된 현재 Cargo의 실측 중심 Z는 상승·하강에 따라 갱신한다. 해당 Hook이 미관측이면 같은 표본의 다른 실측 Hook 기준을 쓸 수 있고, 둘 다 없으면 마지막 추정 중심을 유지한다. 실제 분리·관측 소실 해제 및 Cargo ID 변경 시 기록을 초기화한다. 지면 접촉 완료나 일시 IDLE만으로 같은 Cargo 기록을 지우지 않는다.

실측 Raw, 추적 중심, 관측 양 끝, Cargo/Hook/Ground 검출 및 FSM은 변경하지 않는다. 추정 박스는 현재 포인트 전체를 의미하지 않는다. RViz 기존 marker 토픽에 이 형상을 표시하고 실측 Raw는 녹색으로 그대로 표시한다. 공개 ROS centroid 값은 기존 실측을 유지하며, 새 박스 중심을 실측 centroid로 바꾸지 않는다. 현재 관측 길이 표시는 FRAGMENT로 명시해 확정 길이와 구분한다. ROS/Redis 공개 Key는 추가하지 않는다.

검증은 원본 Raw+TF 37프레임 전체를 새 Engine과 실제 새 Node에 각각 입력했다. 이전에는 짧은 결측·조각 방향 변화로 후보 확인/ID가 초기화되어 새 프로세스에서 전부 IDLE이었다. 같은 Hook·높이·원래 큰 후보 범위가 일치하는 미확정 조각의 연속성을 유지하도록 보완했고, 결측 시간을 제외한 실측 2초가 쌓이면 확인한다. 기본값에서는 Cargo 확인의 실제 관측을 길이 확정에도 공유해 추가 2초 대기를 없앴다. 현재 F28~F37 SUSPENDED, ID1 및 12.488967m를 유지하며 실제 Node와 Engine 실측 audit가 37프레임 모두 일치한다. 다른 Bag은 재생하지 않았다.

물체가 Hook에 대해 실제 회전·수평 진동하면 추정 박스가 실제 형상을 늦게 따라갈 수 있다. Raw가 이를 그대로 보여준다. 이 형상은 연속적인 표시를 위한 추정치이며 상승·하강·충돌 거리·지면 접촉 판정의 근거로 재사용하지 않는다. 배경 활동 비교에서는 Cargo 제외 영역을 정의하는 데만 사용한다.

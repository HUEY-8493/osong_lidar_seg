# Crane V2 · 최대 관측 길이 유지

## 현재 정책

- 처음 IDLE에서는 현재 실측 길이를 그대로 출력한다.
- 같은 Cargo의 실제 연결 관측을 기본 2초 확인한 뒤 SUSPENDED/LIFTING/LOWERING 작업에 진입하면 그 실제 관측의 **최대값**으로 길이를 확정한다. Cargo 확인 시간과 길이 확인 시간을 공유하며 추가로 중복 2초를 기다리지 않는다. IDLE 동안 기록한 형상은 작업 진입 전에는 고정 출력하지 않는다. 과거의 최소 지지 길이 방식은 사용하지 않는다.
- 같은 Cargo에서는 확정 길이가 줄지 않는다. 더 짧은 부분 관측이나 짧은 상태 변화로 실측 길이에 되돌아가지 않는다.
- 더 큰 현재 DIRECT 형상이 같은 Cargo로 채택되고 Hook과 직접 연결된 조건을 만족하면 즉시 최대 길이를 확장한다. 멀거나 연결이 확인되지 않은 물체를 새로 선택하는 규칙은 추가하지 않았다.
- 길이를 확정한 이후에는 같은 Cargo의 일시 IDLE이나 GROUND_CONTACT 작업 완료 중에도 큰 길이를 유지한다. 처음 IDLE의 미확정 상태와 구분한다. 작업 종료 상태의 판정 자체는 변경하지 않는다.
- 양쪽의 실제 관측으로 기존 Hook 분리 조건이 0.3초 지속되거나, 기존 소실 허용/급감 유지창 이후 마지막 DIRECT로부터 1.3초 이상 Cargo가 소실되면 길이 기록을 해제한다. Cargo ID 변경·Engine reset도 초기화한다. 단순 Hook 미관측, Z 변화만으로 분리나 길이 감소를 만들지 않는다.

## 공개 출력과 실측

ROS beam_length/beam_length_locked와 Redis object_length, RViz의 추정 박스 길이에 같은 확정 최대값을 사용한다. Cargo.length/Output.measured_cargo_length 및 Raw 양 끝은 실제 관측 또는 기존 3초 유지 형상이며, 최대 길이가 현재 모두 실측됐다는 뜻은 아니다. 초록 Cargo Raw는 현재 관측 그대로이므로 가림에 따라 짧아질 수 있다. 고정된 Raw를 만들어 길이가 유지되는 것처럼 표시하지 않는다.

`cargo_length_confirm_sec=2.0`은 시작 전용 파라미터다. 기존 3초 급감 박스/상태 유지는 별도로 유지하며, 3초가 끝나도 같은 Cargo의 최대 길이는 줄지 않는다. 이 최대 길이는 Motion/상승·하강 판단이나 Ground clearance 근거로 사용하지 않는다.

## 한계와 검증 범위

가장 긴 선택을 선호하므로 다른 구조물 혼입으로 크게 관측된 값도 유지될 수 있다. 실제 길이가 정확하다는 보증이 아니다. 가상 Hook과의 실제 연결/분리 판단은 기존 공간·관측 검사를 사용한다. 이번 변경은 사용자의 테스트 생략 요청에 따라 Rosbag/동작 테스트 없이 반영했고, 이전 HTML 그래프와 테스트 통계는 이번 정책 이전 결과다.
